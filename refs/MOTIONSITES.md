# MotionSites: второй проход по портфолио

21 октября 2026. MCP `motionsites` уже зарегистрирован в конфигурации Codex по адресу пользователя. Штатный OAuth завершён пользователем; проверены initialize, tools/list, поиск и получение полных промптов. Использована существующая авторизация, дублирующий сервер не добавлялся.

## Прочитанные референсы

| Референс                                                                   | Что адаптировано                                                                                                                             |
| -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| [3D Jack Portfolio](https://motionsites.ai/?prompt=3d-jack-portfolio-hero) | Предыдущий проход: появление крупных слов по очереди, металлический градиент заголовка, связь типографики и собственного объёмного знака AZ. |
| [3D Character Studio](https://motionsites.ai/?prompt=3d-character-studio)  | Выраженные интерактивные действия: выбор проекта, контраст выбранного состояния, реакция на управление.                                      |
| [Space Voyage](https://motionsites.ai/?prompt=space-voyage)                | Выбор сцены и переход в следующий пример, раскрывающаяся рамка при смене демо, счётчик текущего проекта.                                     |

Внешние видео, модели, шрифты, логотипы, тексты и контактные данные из промптов не копировались. Сохранены Geologica, цвета AZ, собственная последовательность кадров и пять существующих демо. После получения трёх бесплатных промптов сервер сообщил `free_prompts_remaining: 0`; покупка тарифа не выполнялась.

## Изменения

- Вместо одного MOLA и четырёх ссылок на главной появилась витрина пяти работающих проектов. Их отдельные страницы также доступны.
- Выбранный проект раскрывается в общей сцене с инструкцией и ссылкой на услугу. Есть явная кнопка следующего примера, без обязательного свайпа.
- Посещённые демо остаются смонтированными и сохраняют состояние при переключении. Например, корзина MOLA не сбрасывается после просмотра других проектов. Скрытые панели исключены из навигации.
- Счётчик 01/05 отражает фактический выбор; изменение проекта объявляется вспомогательным технологиям.
- По просьбе пользователя цифровые кнопки глав убраны: логотип открыт, сцены меняются при прокрутке.
- Reduced motion отключает раскрытие сцены и сохраняет доступ ко всем демо. Первый экран в этом режиме показывает главы обычным потоком.
