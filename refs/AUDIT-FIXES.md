## Команды проверки

- `pnpm typecheck`
- `pnpm design:lint`
- `NEXT_PUBLIC_BASE_PATH=/ilyas-azelkhanov-portfolio NEXT_PUBLIC_SITE_URL=https://elazazel.github.io/ilyas-azelkhanov-portfolio pnpm build` (переменные задаются способом используемой оболочки)
- `pnpm check:release` - метаданные, доступность, адаптивность, hero и полные сценарии пяти демо
- `pnpm check:playground`
- `pnpm check:showcase`
- `pnpm shots / /brief/ /work/`
- `pnpm audit`

`pnpm design:lint` проверяет YAML-контракт, корректность токенов, ссылки на них, синхронизацию с generated JSON и 16 цветовых пар текста. Это не утверждение о полной WCAG-проверке сайта.

`pnpm build` перед сборкой генерирует четыре SVG из исходной геометрии. Цвета берутся из DESIGN.md и палитры демо. Небольшая архитектурная арка остаётся inline.

Проверки и генератор работают без сервера приложения, на точном статическом экспорте. Материалы исходного аудита и снимки остаются локально в `audit/2026-10-30/`, автоматически в публикацию они не включаются.

Развитие подтверждённых клиентских кейсов, портрет автора и подключение аналитики не включены в технические исправления: для этого требуются отдельные материалы или решение владельца. Факты и результаты клиентов не придумывались.
