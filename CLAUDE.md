# azelkhanov-site

Многостраничный сайт услуг Ильяса Азелханова (Алматы). Направления: сайты, Telegram Mini Apps, боты, AI-автоматизация, тренинги (корпоративные и личные). Сайт сам является демонстрацией уровня разработки. Бизнес-цель: заявка в WhatsApp или Telegram. Сайт только на русском (решение Ильяса 20.10.2026: казахские версии убраны).

## Стек (не менять без согласования)
- Next.js 16.4 (App Router, Turbopack), React 19.3, TypeScript 7 strict, pnpm
- `output: 'export'` + `trailingSlash: true`: сайт - чистая статика в `out/`, хостинг hoster.kz (зона .kz обязана жить на серверах в РК). Никаких middleware, ISR и серверных функций; route handlers - только `force-static` (они превращаются в файлы: `llms.txt`, `sitemap.xml`, `robots.txt`, `manifest.webmanifest`)
- Tailwind CSS 4.3 + shadcn/ui (Base UI). Готовые анимированные блоки (Magic UI / Aceternity / React Bits / 21st): максимум 4 на сайт, всегда перестилизованы под токены
- GSAP 3.15 + ScrollTrigger + SplitText через @gsap/react (useGSAP, cleanup обязателен): скролл-сцены
- Motion 14 (`motion/react`): hover/tap/layout состояния компонентов. Не два движка на одном элементе
- View Transitions (React 19.3) для переходов между страницами; без поддержки браузера - обычная навигация
- Lenis 1.3: только desktop (на телефоне нативная прокрутка лучше); выключен при reduced motion; один общий rAF через gsap.ticker
- Звук и вибрация: `lib/sfx.ts` (Web Audio, без файлов) и `lib/haptics.ts`; подключаются атрибутом `data-fx="press|select|hover"`, обработчик один - `components/motion/Feedback.tsx`
- three / R3F / drei: ТОЛЬКО для одной сцены hero на главной (`components/hero-scene`), lazy, desktop + capable mobile
- Язык сайта: только русский, без next-intl и `/kk`-страниц
- @serwist/turbopack: manifest + offline-страница. Push, background sync: не делать
- Деплой: GitHub Actions → `pnpm build` → SFTP на hoster.kz (доступы в GitHub Secrets). Превью - `dev.azelkhanov.kz` за basic auth. `.htaccess`: HTTPS-редирект, 404, кэш статики

## Команды
- `pnpm dev` / `pnpm build` / `pnpm lint` / `pnpm typecheck`
- `pnpm shots [маршруты]`: Playwright-скриншоты 375 / 768 / 1440 из `out/` в `./shots` (сначала `pnpm build`); печатает горизонтальный overflow и ошибки консоли
- `pnpm design:lint`: линтер DESIGN.md (токены и WCAG-контраст)
- `pnpm tokens`: DESIGN.md → `app/tokens.css` + `content/tokens.json`. Запускать после любой правки токенов
- `pnpm fonts`: `brand/fonts-src/*.ttf` → `public/fonts/*.woff2` + `app/font-faces.ts` (нужны `fonttools`, `brotli`)

## Демо (доказательство на каждой странице услуги)

## Дизайн
- Только токены из DESIGN.md. Никаких сырых hex/px/радиусов в компонентах.
- Шкалы Tailwind по умолчанию отключены (`app/tokens.css`): существуют только наши цвета, радиусы и отступы. Отступы - ИМЕНОВАННЫЕ, не кратные 4: `p-5` = 24px, `p-7` = 48px, `p-10` = 144px; `w-20`, `p-12` и т.п. не существуют. Типографика - только утилиты `t-<токен>` (плавные между 375 и 1440).
- Синее - скруглённое (`rounded-pill`), ink - острое (`rounded-xs`/`none`). Синий текст - только `primary-deep`.
- Одна сильная сцена на страницу. Главная: 3D-hero. Страница услуги: её демо. Остальное тихое - типографика и отступы.
- Запрещено: Inter / Roboto / Space Grotesk как display; фиолетово-синие градиенты; кремовый фон + терракота; near-black + кислотный акцент; сетки одинаковых скруглённых карточек с мягкой тенью; eyebrow-лейблы капсом; «→» после ссылок; 01/02/03 вне реальных последовательностей; акцент одного слова в заголовке; fade-up на каждой секции; кастомный курсор; прелоадер и счётчик 0%; автозвук до действия пользователя (звуки - только в ответ на тап/клик/клавишу, S8); scroll-jacking и горизонтальный скролл на mobile.
- Любой шрифт обязан содержать: Әә Ғғ Ққ Ңң Өө Ұұ Үү Һһ Іі. Проверь до подключения.

## Mobile / PWA
- Mobile-first: сначала 375px, потом desktop.
- `@media (display-mode: standalone)`: нижний tab bar (Главная, Услуги, Работы, Связаться), `env(safe-area-inset-*)`, без браузерного футера.
- Service worker не кэширует `/api/*`, формы и стрим чата.
- Install-подсказка только после вовлечённости (2-й визит или 3+ страницы), никогда в in-app браузерах Telegram/Instagram.

## Бюджет производительности (mobile, каждая страница)
- LCP ≤ 2.5s, INP ≤ 200ms, CLS ≤ 0.1; Lighthouse mobile ≥ 90
- Initial JS: каркас Next 16 + React 19 сам весит ≈171 KB gzip (≈148 KB brotli) - это пол, ниже не уйти без смены фреймворка. Собственный код страницы поверх каркаса ≤ 40 KB gzip. GSAP, ScrollTrigger, Lenis, частицы и демо - только динамический `import()` (по idle или IntersectionObserver), никогда статический импорт. На hoster.kz включить brotli
- Выразительный слой - только сигнатуры S1–S6 из DESIGN.md → Expressive layer; прототипы живут на `/lab`
- ≤ 2 семейства шрифтов: Geologica (весь текст) + Fira Code (только код и метрики в демо); один woff2 на семейство из `pnpm fonts`; изображения AVIF, hero-постер ≤ 120KB
- LCP-элемент: текст или постер, никогда canvas/iframe
- Паритет: телефон получает те же эффекты, что desktop (DESIGN.md → Expressive layer → Паритет). Не отключать эффекты по типу устройства, памяти или Save-Data. Единственный выключатель - `prefers-reduced-motion`
- WebGL/canvas: DPR ≤ 2, пауза вне экрана, обработка потери контекста
- Анимировать только transform/opacity; reduced motion через gsap.matchMedia и MotionConfig reducedMotion="user"

## Данные и право
- Волна 1 не хранит персональные данные: бриф считается в браузере и уходит предзаполненным текстом в WhatsApp/Telegram.
- Без отдельного решения в SPEC.md: никаких форм с ПДн, логов чата, Supabase/Resend (локализация ПДн в РК с 25.08.2026).
- Аналитика: только Yandex Metrica (`next/script` lazyOnload); полевые CWV - через `web-vitals` в параметры визита Метрики. Пакеты Vercel не используем (хостинг не Vercel).

## Как работать
- Используй Context7 для документации библиотек без напоминаний.
- UI/UX Pro Max вызывай только по моей просьбе (фаза 1 - черновик дизайн-системы, фаза 7 - чек-лист). Во всех остальных случаях источник правды - DESIGN.md.
- Промты из внешних библиотек (MotionSites и др.) - только как референс: переписывай под токены DESIGN.md и бюджет производительности, не вставляй как есть.
- Видео-фоллбэки демо делаем через HyperFrames из тех же сцен; кладём в `public/media` (AV1 + H.264 + постер), без звука.
- Новая страница или демо: сначала план (plan mode), потом код.
- После любого визуального изменения: `pnpm shots`, сравни с DESIGN.md, перечисли расхождения, исправь. Только потом «готово».
- Одна страница/секция = одна задача = один коммит. Перед коммитом: typecheck + build.
- При компактизации сохраняй список изменённых файлов и открытых TODO(ilyas).
