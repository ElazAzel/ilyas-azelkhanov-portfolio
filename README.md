# Портфолио Ильяса Азелханова

Экспертное портфолио Digital Product Designer & Web Service Expert. Сайт показывает не только интерфейсы, а полный путь от бизнес-проблемы и исследования до работающего цифрового продукта и модели ценности.

## Стек

- Next.js App Router
- TypeScript
- Tailwind CSS
- Motion
- Lucide Icons
- локальная типизированная структура данных проектов

## Локальный запуск

```bash
npm install
npm run dev
```

Проверки:

```bash
npm run typecheck
npm run build
```

## Переменные окружения

Скопируйте `.env.example` в `.env.local`.

- `NEXT_PUBLIC_SITE_URL` — канонический адрес сайта.
- `NEXT_PUBLIC_FORM_ENDPOINT` — endpoint Formspree/Web3Forms. Если пусто, форма работает в безопасном демонстрационном режиме.

## Проекты

Данные находятся в `src/data/projects.ts`. Чтобы добавить проект:

1. Добавьте seed в массив `seeds`.
2. Укажите уникальный `slug`, категорию, задачу, ценность, инсайт и функции.
3. Для реального проекта установите `real: true` и при необходимости `liveUrl`.
4. Для концептуального проекта не задавайте `real`: интерфейс автоматически покажет корректный бейдж и только целевые показатели.

Сейчас в каталоге 20 проектов: 2 реальных и 18 концептуальных; в каждой из шести концептуальных категорий — по три проекта.

## Контакты

Контактные ссылки и подписи вынесены в `src/data/site.ts`. Не добавляйте неподтверждённые контактные данные.

## Развёртывание на Vercel

Импортируйте репозиторий в Vercel, задайте переменные окружения и используйте стандартную команду сборки `npm run build`. Next.js определяется автоматически.
